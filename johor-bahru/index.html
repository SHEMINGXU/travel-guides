去程 Tuas · 返程 Woodlands
过关交通与支付详情
  • 去程（Tuas 二通道）：Tuas Link MRT 绿线终点站 → CW7（该站唯一跨境巴士，步行约 2min 到对面站牌 25421；关口不可步行，必须坐巴士）→ Tuas Checkpoint 下车出境 → 同车过桥到 Sultan Abu Bakar CIQ（2nd-Link 关口）下车入境 → 出关转 CW7L（出示 CW7 车票／刷同一卡）→ Mydin Anjung（Anjung Medini）下车步行约 10min 到 RUD。全程约 1h、CW 巴士 2026-10 起全线无现金（刷银行卡／SimplyGo／ezlink，深夜清早 ezlink 可能不可用，备银行卡兜底）；CW7 每日 05:00–22:15、约 15min 一班；CW7L 从 CIQ 出发高峰约 30min 一班（首班 5:30、末班 22:30），衔接顺畅。拥堵：周六早上 Tuas 出关属低峰（6am–4pm 为整周最佳窗口，清关通常 <10min），9:00 进关基本顺畅；10-17 周六无学校假期叠加，比 Woodlands 高峰好很多。

  • 证件与过关：中马护照互免签至 2026-12-31；MDAC 抵马前 3 天填（imigresen-online.imi.gov.my，交通填巴士车牌、住宿填酒店地址，提交后截图保存）；中国护照走马来西亚自助闸机（e-gate 刷护照＋人脸识别），护照按要求方向放（部分闸机竖放），失败走人工递护照＋MDAC；新加坡侧红色自助通道可 group 一起过；过关全程禁止录像。
  • 货币与换汇：汇率参考 1 SGD≈3.19 MYR；建议换 RM250–300（约 S$80–95）——新加坡换好，或过关后 City Square 一楼换汇点补；别在新山 ATM 取现（每笔 S$7 服务费＋转换费不划算）。
  • 支付：DBS Visa／Mastercard（信用卡／借记卡）在新山商场、餐厅、GSC、Grab 通用；境外刷卡手续费最高 3.25%——大额（RUD、4DX、酒店、购物）刷卡，小额现金。
  • 现金刚需：Hutan 滑索 RM90（2 人，去的话）＋夜市／宵夜 RM120–150＋零花与打车兜底 RM50–80。
  • DBS 出发前：卡默认境外芯片/闪付可直接刷、无需设置；可选：digibank → More → Travel Mode 填 10-17 马来西亚（防大额消费被风控拦截）；借记卡记好 PIN（插卡/取现用）；境外磁条默认关闭属防盗刷设计，遇到老旧刷卡机刷卡失败才需临时开启。
  • 提醒：各点营业时间出发前再现场核实一次（网上攻略可能过时）；返程如需申报新加坡入境（SG Arrival Card，按个人身份确认）。

雨天／雷暴兜底

RUD 户外赛道关闭 → 改 EVOLT 室内卡丁车（Day1 下午）；JetSki 雷暴取消 → 改 Day2 上午补玩或改逛街（雷暴可退款）。

满场／售罄应对

4DX 限时特映售罄 → 改同影院普通场次或 21:00 后场次；JetSki 满场 → 优先 15:30 订不到按 16:00。

精力／天气收缩

Mount Austin 精力不够 → 直接回酒店（Mid Valley／KSL 周边宵夜）；烟霾严重 → 高空观景（Skyscape）取消，保留室内项目。
